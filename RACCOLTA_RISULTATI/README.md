# RQ2 results collection

This directory contains the development artifacts, evaluations and summaries
used for RQ2.

`INVENTARIO.md` is a frozen historical artifact referenced by the evaluation
manifests. It intentionally preserves the paths recorded when the experiments
were documented, so that its registered SHA-256 remains verifiable.

The editorial-copy directory was subsequently renamed without changing any
experiment, result or metric:

```text
tesi_anonimizzata/ -> nomi_aziendali_cambiati/ -> thesis_editorial_copy/
```

The current paths are recorded in `inventario.json`. The public-facing copies
are available in [`../thesis_editorial_copy/`](../thesis_editorial_copy/).
